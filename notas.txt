### Implementación: Pago con QR de MercadoPago

**Meta**: Reducir comisiones de ~3.5% a 0.8% usando QR de MercadoPago.

**Estado**: ❌ SIN COMPLETAR - hay problemas con la API de MP

## Lo que se implementó:

### Backend (`backend/main.py`):
- Endpoint `/api/pagos/qr` - crea orden de pago QR
- Endpoint `/api/pagos/webhook-qr` - recibe notificaciones de pago
- Endpoint `/api/pagos/qr/{id}/status` - verifica estado
- Configuración en `config.py`: MERCADOPAGO_QR_USER_ID, MERCADOPAGO_QR_EXTERNAL_POS_ID

### Frontend (`frontend/index.html`):
- Selector entre "Link de Pago" y "QR"
- Modal que muestra código QR
- Botón "Verificar Pago"
- Código pusheado y deployado

### Problemas encontrados:

1. **API vieja** (`/mpmobile/instore/qr/{user_id}/{external_id}`):
   - Error: `invalid_caller_id` - el user_id no es compatible

2. **API nueva** (`/v1/orders`):
   - Error: `pos_not_found` - la caja no está registrada para esta API

### Análisis:

Hay dos sistemas de QR en MercadoPago:
- **Sistema viejo** (`/mpmobile/instore/`): requiere user_id + nombre de caja
- **Sistema nuevo** (`/v1/orders`): requiere external_pos_id específico

La caja "GetAccessQR" existe pero está configurada para el sistema viejo, no para v1/orders.
